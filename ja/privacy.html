プライバシーポリシー利用規約権限と外部サービスデータ管理と削除ヘルプとサポート

プライバシーポリシー

更新：2026年10月20日 · VeriPic 1.1。VeriPic は端末内の画像解析と任意のクラウド詳細スキャンを提供します。登録は不要です。広告、アプリ間トラッキング、第三者の解析 SDK は使用せず、データを販売しません。

端末内解析は、選択または共有した画像と埋め込みメタデータのみを読み取ります。履歴にはサムネイル、日時、判定、解析情報を端末内で保存します。共有画像は非公開の App Group 受信箱に一時保存され、アプリが読み取った後に削除されます。書き出した履歴やレポートには私的な画像や解析情報が含まれる場合があります。Apple の設定により端末バックアップにアプリデータが含まれることがあります。

クラウド詳細スキャンでは、長辺最大 1024 ピクセルの JPEG、知覚画像ハッシュ、ランダムな端末 ID、匿名アカウント ID を HTTPS で Cloudflare Worker に送信し、画像を Hive に転送して AI コンテンツを検出します。VeriPic は送信写真を永続保存しません。Hive の処理と保持には同社の適用規約とポリシーが適用され、画像の非保持やサービス改善への不使用を保証できません。機密画像や提出する権利のない画像を送らないでください。国外で処理される場合があります。

初回のクラウドスキャン前に同意を求めます。同意は設定で撤回するまで、自分で開始する今後のクラウドスキャンにも適用されます。写真をバックグラウンドで自動送信しません。拒否・撤回後も端末内解析は利用できます。撤回は今後のスキャンを止めますが、送信済みの要求や既存のサーバー記録は取り消しません。

オンライン時には写真送信への同意前でも、端末・アカウント ID により無料枠とクレジットを照会する場合があります。支払い情報は Apple が処理します。サーバーはクレジット付与と返金のため、匿名アカウント ID、残高、検証済み取引情報（取引 ID、商品、数量、環境、状態、日時）を保存します。アカウント ID は Apple 購入トークンとしても使われ、iCloud キーチェーンで同期される場合があります。これらは活動や購入を関連付ける仮名 ID であり、氏名、メール、Apple ID ではありません。

Worker は画像ハッシュ、スコア、推定生成器、キャッシュ情報を最大 30 日保持します。ネットワークアドレス（IPv6 はプレフィックス）と端末 ID を不正利用防止に使います。日次カウンターは 2 日、月次は 40 日で期限切れとなり、データベースの期限切れ記録は後の成功したスキャン時に削除されます。期限切れは即時の物理削除を保証しません。アカウント・取引記録はクレジット、返金、適用義務に必要な間保持します。Cloudflare、Apple、Hive も必要なネットワーク・サービス情報を別途処理する場合があります。

履歴画面で端末内記録を閲覧・書き出し・削除でき、設定でクラウド同意を撤回し、iOS 設定で写真追加権限を管理できます。サーバー記録の開示・訂正・削除は treeui.old@gmail.com にまず依頼内容をお送りください。照合のためバックアップコードを非公開でお願いする場合があります。コードを公開せず、Apple パスワードや確認コードを送らないでください。削除は残クレジットの復元に影響するため、処理前に範囲を説明します。未完了の取引や適用義務に必要な記録は保持する場合があります。

サポートへの連絡時は、提供されたメールアドレス、本文、添付を対応のために処理します。公開サイトのホストは IP、ブラウザー情報、安全ログを処理する場合があります。ページに広告・解析スクリプトはありません。子どもは保護者の指導下で利用してください。ストア年齢区分はクラウド処理がすべての子どもに適することを意味しません。子どもの提出データについてはご連絡ください。重要な変更は本ページやリリース情報で知らせ、必要に応じ同意を再取得します。

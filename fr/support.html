Aide et assistance

Choisissez une photo ou partagez-en une avec VeriPic, puis consultez la conclusion et les signaux d’analyse. Le redimensionnement, les captures d’écran, la compression et les générateurs peu connus peuvent influencer la détection. L’analyse locale fonctionne sans réseau.

Si l’analyse cloud échoue, vérifiez le mode hors ligne, l’autorisation cloud, la connexion et le quota. Vous pouvez continuer à utiliser l’analyse locale. Pour les crédits, utilisez « Restaurer les achats » pour relancer les transactions en attente ou restaurez votre compte anonyme avec le code de sauvegarde de votre autre appareil. Les achats consommables terminés nécessitent le code du compte d’origine ou le trousseau iCloud.

Pour toute demande d’assistance ou relative à la confidentialité : treeui.old@gmail.com. Indiquez la version de l’app et d’iOS, les étapes suivies et le texte de l’erreur. Retirez les images privées inutiles et n’envoyez jamais de mot de passe ou de code de vérification Apple. Ne partagez le code de sauvegarde du compte qu’en privé, si cela est nécessaire pour vérifier une demande relative aux crédits ou à la suppression.

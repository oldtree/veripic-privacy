Données et suppression

Historique local : ouvrez Historique pour consulter les enregistrements. Ouvrez un rapport enregistré pour supprimer une analyse, ou utilisez le menu de l’historique pour exporter ou effacer tout l’historique. La suppression retire la vignette et le rapport stockés, sans toucher à la photo d’origine dans votre photothèque. Elle est irréversible dans l’app.

Copies : effacer l’historique ne supprime pas les fiches de rapport enregistrées dans Photos, les fichiers exportés, les pièces jointes envoyées à l’assistance ou les copies partagées avec d’autres personnes. Supprimez-les séparément. Les fichiers temporaires de rapport et d’export peuvent rester dans le cache de l’app jusqu’au nettoyage du système ou à la suppression de l’app. Une image partagée non lue reste dans la boîte de réception de l’App Group jusqu’à ce que l’app la traite. Les sauvegardes de l’appareil gérées par Apple doivent être gérées séparément.

Contrôle du cloud : retirez l’autorisation d’analyse cloud dans Réglages pour bloquer les prochains envois de photos. Le mode hors ligne bloque aussi les analyses cloud. Aucune de ces actions ne supprime les résultats déjà mis en cache, les enregistrements de transactions ou une image déjà transmise à un fournisseur. Les durées de conservation du cache et des compteurs sont expliquées dans la Politique de confidentialité.

Il n’existe aucun compte avec connexion enregistrée. Les crédits sont associés à un identifiant de compte anonyme, qui peut subsister après la suppression de l’app via le trousseau et se synchroniser sur d’autres appareils. Supprimer l’app ou l’historique ne ferme pas ce registre et n’annule ni ne rembourse un achat. Vous pouvez supprimer le compte cloud dans Réglages > Sauvegarde et récupération.

Supprimer le compte cloud dans les Réglages efface son solde et dissocie les enregistrements de transactions d’achat conservés de l’identifiant de compte. Les crédits restants sont perdus, les achats ne sont pas remboursés et les rapports et photos locaux restent sur l’appareil. Les transactions nécessaires aux remboursements ou aux obligations applicables peuvent être conservées sans ce lien. Pour demander l’accès, la rectification ou une autre suppression, écrivez à treeui.old@gmail.com ; nous pourrons demander en privé le code de sauvegarde afin de retrouver les données. Ne le publiez pas. Les données détenues par Hive et Apple relèvent de leurs propres procédures.
